# このプロジェクトの完了条件

ユーザーが指定したゴールは、**何本か実際に動画を公開し、反響を見て分析し、動画を修正するところまで**。

管理画面、収集コード、架空デモの完成で終了しない。初回は3本を制作・公開し、その反響を踏まえて変更点を一つ選び、修正版に反映する。実投稿や実測をしていないものを成功として扱わない。

## 初回の進め方

1. ポコの日本語絵本ショートを3本制作する。
2. 投稿先のチャンネルを確認し、完成動画・タイトル・説明・子ども向け設定を確認して公開する。
3. 実動画IDと公開日時を記録し、24時間・72時間後の反響と、遅れて届く詳細分析を取得する。
4. 観測事実、不確実性、次に変更する要素を分けて分析する。
5. その変更を反映した動画を書き出す。

最初の3本は内容の方向性を探す観察であり、厳密なA/B実験と呼ばない。少数・欠測時に無理な結論を作らず、追加観測が必要ならその理由を残す。

進捗と完了条件は `production/pilot.json` に記録する。動画の制作情報・公開情報・実測結果は、別々に追跡する。
