# 最初の24本の試験計画

24本を先に全部生成せず、各段階の結果を見て次を決めます。成功保証や必要サンプル数の統計的算出ではありません。

## 共通条件

オリジナルのこぐま「ポコ」。茶色い体、黄色いスカーフ、小さなかご。日本語、柔らかい絵本風、縦型9:16、30〜45秒。声、字幕の大きさ・位置、画風を維持します。子ども向け物語とサービス紹介は別シリーズ・別比較計画として扱います。

## 1〜12本：方向性を探す

| 型 | 4本の別エピソード例 |
| --- | --- |
| 一緒に探す話 | 赤いりんご、青いボール、丸いもの、なくしたスカーフ |
| 小さな意外性 | 空の箱、雨の日の音、不思議な影、かごの中の葉っぱ |
| 日常の問題解決 | おもちゃを分ける、片付ける順番、待ち合わせ、順番を待つ |

探索結果を一つのA/Bに混ぜません。公開時間・テーマ・修正回数を記録し、再生数に加えて日別の視聴状況も見ます。現在の比較エンジンは冒頭のA/B用なので、この探索の型選びは制作側で判断します。

## 13〜20本：冒頭だけを比較

残した一つのシリーズで、A「質問から始める」とB「見せ場を先に出す」を各4本。公開前に比較計画を保存します。題材の難しさを近づけ、A/Bの順番と時間帯を偏らせません。例えば公開順は A・B・B・A・B・A・A・B。曜日・時刻の影響は残るため、観察比較として扱います。

各動画の公開72時間後の観測が揃ってから比較します。同じMP4の再投稿は独立サンプルに数えません。20%以上の中央値の差は再検証を始める設定値であり、有意差ではありません。

## 21〜24本：別の話で再確認

A/Bを各2本追加。改善案にある冒頭だけを新しいエピソードに反映し、声・尺・画風・字幕を維持します。台本、各場面の色と内容、キャラクターの一貫性、読み方を確認します。傾向が続かなければ結論を固定せず、試験を追加します。

## 制作時の確認

- 質問に答える色・形と絵が一致しているか。
- 2秒の思考時間をナレーションで読み上げていないか。
- 台本の自然さ、字幕の読みやすさ、音量。
- 子ども向け設定、素材と音声の利用条件。
- 完成MP4と記録するハッシュが一致しているか。

日別分析の平均視聴率を完視聴率と呼ばず、再生数だけで教育的価値や収益性を判断しません。
