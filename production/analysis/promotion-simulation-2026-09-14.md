## 判断

前の「視聴者の拡大・媒体2,700円」の案は、比較と検証が不足していたため、そのまま実施する推奨を撤回する。今回、同じ動画と対象条件で、2つの広告目的×5つの予算についてYouTube Studioの予測を実際に取得した。

最初の視聴を集めて内容を検証する目的では、「動画の視聴回数」のほうが予測上の費用が低い。媒体1,000円・税込1,100円なら450〜1,100回、媒体2,700円・税込2,970円なら1,200〜3,100回という表示だった。ただし、これらは広告の視聴イベントの予測であり、独立した視聴者数・完視聴数・子どもが楽しんだ人数ではない。

**広告の視聴回数には条件付きの予測があるが、ファン化・継続視聴・収益回収については、高精度の予測を名乗れるデータがない。** 予算を増やせばこの欠落が自動的に解消するわけでもない。現時点で1万円の広告を行う根拠は不足している。

## 公式予測を使った予算比較

費用は全額消化した場合。日本国内のGoogle広告に関する公式の消費税10%を使い、媒体費とは別に税込額を計算した。実際の請求書はまだ存在しないため、請求額の確定値ではない。[Google広告：各国の税金、日本の項目](https://support.google.com/google-ads/answer/2375370?hl=en-AU)

| 媒体予算 | 税込支出の計算値 | 視聴回数目的：視聴予測 | 視聴者拡大目的：視聴予測 |
| ---: | ---: | ---: | ---: |
| 1,000円 | 1,100円 | 450〜1,100回 | 50〜220回 |
| 2,700円 | 2,970円 | 1,200〜3,100回 | 140〜540回 |
| 3,000円 | 3,300円 | 1,300〜3,500回 | 160〜590回 |
| 5,000円 | 5,500円 | 2,500〜6,400回 | 260〜960回 |
| 10,000円 | 11,000円 | 6,000〜16,000回 | 490〜1,800回 |

税込上限3,000円なら、媒体3,000円を入力する案では上限を超える。媒体2,700円なら、10%税込計算は2,970円になる。別に画面で案内されたカード確認の一時請求2,000円は、通常取り消される一時的な資金拘束であり、広告費や広告効果の分母に加えていない。

## 再生回数を成果へ読み替えない

Studioの展開説明は「プロモーションの視聴回数」を広告のクリックから視聴につながる回数として説明し、公開動画の総視聴回数と区別していた。ただし広告の課金・視聴計測には形式ごとの条件があるため、この文言だけから全視聴が同一条件のクリックや完視聴だとは推定しない。今回のシミュレーションは、UIの「推定視聴回数」をそのまま原指標として使う。

「視聴者の拡大」の推定エンゲージメントは、媒体1,000・2,700・3,000円では「100件未満」、5,000円では77〜130件、1万円では170〜250件。登録やコンテンツ操作などを含む行動数であり、登録者数でも独立した人の数でもない。「100件未満」を50件という期待値や確定99件へ置き換えない。視聴回数目的の画面には、この予測は表示されなかった。

YouTube公式の「後続視聴」は、広告との接点のあとに見た動画ごとに数える指標で、「視聴者の拡大」でのみ利用できる。視聴回数目的の方が安くても、同じ後続視聴指標で効果を比較できるとは限らない。また広告の成績は通常のおすすめの評価に直接使われるものではなく、広告由来の登録・再生時間も収益化の要件とは区別される。[YouTube公式：Promoteと後続視聴](https://support.google.com/youtube/answer/12199105?hl=ja)

## 継続視聴の感度分析

実測がないので、継続視聴を予測値として算出することはしない。代わりに「広告100再生あたり、あとで別動画が何回見られるか」という**未検証の仮定**を変え、費用判断への影響だけを示す。人数や転換確率ではなく、視聴イベント同士の比である。次の1・5・10は業界平均でもこのチャンネルの推定値でもない。

媒体2,700円・税込2,970円の例：

| 仮定：広告100再生あたりの追加視聴 | 視聴回数目的の追加視聴計算 | 視聴者拡大目的の追加視聴計算 |
| ---: | ---: | ---: |
| 0回 | 0回 | 0回 |
| 1回 | 12〜31回 | 1.4〜5.4回 |
| 5回 | 60〜155回 | 7〜27回 |
| 10回 | 120〜310回 | 14〜54回 |

例えば「5回」という仮定なら、追加視聴1回あたりの税込費用は、視聴回数目的で約19〜50円、視聴者拡大目的で約110〜424円となる。ただし、同じ仮定を両目的へ置いた算術比較であり、視聴者拡大の実際の追加視聴効率が同じだという意味ではない。その差こそ未測定である。視聴回数目的ではネイティブの後続視聴指標が使えず、仮定どおりの効果帰属ができるとは限らない。

これらは確率分布からの予測区間ではない。件数が小数になるのは計算モデルの値のためで、実際には視聴イベントは整数になる。広告を見られても次の動画への視聴が0という結果は十分に残る。利益や広告費回収期間の計算には、収益や顧客価値の根拠も必要であり、現在は算定しない。

## 予測精度について言えること

| 項目 | 今回確認できること | 確認できないこと |
| --- | --- | --- |
| 条件の再現性 | 同じ対象・動画・日付で10条件を取得し、原表示を保存 | 将来のオークション環境が同じか |
| 費用計算 | 媒体費、消費税仮定、一時請求を区別 | 実消化額と最終請求額 |
| 視聴の見込み | 対象アカウントに表示された公式レンジ | そのレンジの被覆確率、最頻値、平均値 |
| 親子への適合 | 日本語の成人向けという配信設定 | 親子で見た人数や満足度 |
| 継続・登録 | 指標の定義と取得制約 | このチャンネルの実際の転換・回遊率 |
| 自然成長 | 後から別の動画を見る接点は作り得る | 広告がなくても得られた視聴との差、将来の自然再生数 |

予測幅を95%信頼区間と称したり、中央値を期待値としたり、根拠のない正規分布・一様分布で乱数を生成したりしていない。UIモデルの計算式、誤差分布、校正データは取得できない。関連するGoogleのReach Plannerも予測は成果を保証しないと説明しているが、それをPromoteの内部計算式と同一だとは扱わない。[Google公式：Reach Plannerの予測](https://support.google.com/google-ads/answer/9427192?hl=en)

審査で配信されない、対象条件や少額予算で配信が進まないケースもある。したがって表の下端は最低保証回数ではなく、0回や範囲外の結果も除外できない。[YouTube公式：配信が少ない場合](https://support.google.com/youtube/answer/16869853?hl=en)

## このアカウントでの次の判断

1. 今回は広告を開始しない。元の2,700円案を既定路線にせず、自然流入の24/72時間観測を継続する。
2. 自然配信が乏しく、広告で初回の視聴データを買うと判断する場合は、まず媒体1,000円・税込1,100円の「動画の視聴回数」を候補とする。これは採算の見込みが立った投資ではなく、費用を限定した内容検証の候補で、実施には別途判断が必要。
3. もし実施するなら、開始前の累積値、実際の配信期間、広告費、広告視聴・表示、入手できる広告流入の視聴時間を同じ期間で保存する。広告経由の視聴から分かる範囲で冒頭や間を一つ改善し、自然流入の維持率へ一般化しない。
4. データが処理済みになってから、実際の視聴単価と事前のレンジを照合する。1回レンジに入っただけでモデルが高精度だとは判断せず、次の同条件の検証で予測と実測を比較する。
5. 継続視聴を主要成果にする段階では「視聴者の拡大」の必要性を再評価する。視聴数だけを安く増やす目的とは、予算と評価指標を分ける。未広告動画への回遊が起こり得るため、それらを厳密な対照群にしない。

初回の視聴サンプルを作る候補は示せる。しかし実際の親子への適合や継続率がない状態で、「費用をかければ何人の固定視聴者が増える」と高精度で提示するのは不適切である。今回の結果を、未測定の成果を含む課金の承認依頼に使わない。
