## 広告案

YouTube公式によると、Promoteは新しい視聴者への広告配信に使える。ただし広告の成績が通常のおすすめの評価に直接使われるわけではない。「視聴者の拡大」では広告との接点の後に別の動画を見る後続視聴を測定できる。広告由来の登録・再生時間と収益化の要件も別である。[YouTube公式：Promote](https://support.google.com/youtube/answer/12199105?hl=en)

| 項目 | 入力済みの案 |
| --- | --- |
| 動画 | [いろあそび3問・24秒](https://www.youtube.com/shorts/DpgabSBgQgk) |
| 目標 | 視聴者の拡大。登録だけでなくチャンネルへのアクセス・後続視聴を重視 |
| 見出し | 親子でいろあそび 3つの色クイズ |
| 説明 | りんご・バナナ・ボール、どっちかな？ こぐまポコと24秒の指さしあそび。 |
| 地域と言語 | 日本・日本語 |
| 年齢と性別 | 18歳以上の各年齢層、年齢不明を除外、性別は限定しない |
| 関心カテゴリ | 未指定。親子向けの文面を使用するが、親だけに配信されるとは断定しない |
| 期間 | 開始日欄9月14日、終了日9月21日。承認が後日なら日付を変更 |
| 媒体予算 | 2,700円の案。請求総額の上限案3,000円に対して300円を留保 |
| AIの表示 | 広告用AIラベルを付ける設定 |
| 状態 | 支払い・請求の最終画面で停止。キャンペーンIDなし、配信なし |

3,000円を入力した時点のUI予測は視聴160〜590回、表示2,700〜6,500回、エンゲージメント100件未満だった。これは推定であり成果保証ではない。その後、媒体予算を2,700円へ変更したため、この予測を現在案の確定値として使わない。

請求画面には、Google広告の新規利用規約への同意と、カード確認のための一時的な2,000円の請求（通常1週間以内に取り消し）が表示された。最終実行は行っていない。予算の承認に加え、この規約と一時請求の確認が必要である。税・手数料等を含む本来の広告支出が承認上限を超える場合は実行しない。支払情報はプロジェクトに保存しない。

広告審査や配信状況により開始まで時間がかかる。予算不足や対象を絞り過ぎた場合も配信が少なくなることがあるため、「作成したらすぐ規定数の視聴が得られる」とは扱わない。[YouTube公式：プロモーションの問題解決](https://support.google.com/youtube/answer/16869853?hl=en)

## 判断に使うデータ

広告を実施する場合は、開始直前のStudio値と開始時刻を保存し、開始24時間後・72時間後・終了後に広告の費用、表示、視聴、後続視聴を確認する。設定上の日付ではなく、実際の配信開始・審査状態を記録する。配信終了後の自然視聴も次の7日間で確認する。承認・開始時に既存の定期確認へ実日付を追加する。

YouTubeは広告と自然流入で視聴維持率等が異なり得ると説明している。動画の公開回数は広告も含み得るので、広告画面の視聴数とStudioの公開回数をそのまま引き算して自然視聴を作らない。出典、対象期間、原指標を分けて記録する。[YouTube公式：プロモーションの評価](https://support.google.com/youtube/answer/16869935?hl=en)、[広告と視聴指標](https://support.google.com/youtube/answer/2375431?hl=en)

- 露出がない：広告の審査・配信状態、対象、予算を確認する。台本の優劣は判断しない。
- 露出はあるが視聴につながらない：親子に伝わる見出し・カバー・最初の問いかけを検証する。
- 見始めるが途中で離れる：取得できた維持率の区間を根拠に、説明や間を一つ直す。
- 広告視聴だけ増え、後続視聴がない：予算を自動追加せず、最初の動画と次の動画のつながりを改善する。
- 後続視聴が発生する：観測期間と費用当たりの件数を示して、同じ視聴者に合う別の内容を次に試す。

少額・少数サンプルの探索であり、目標達成や再現性は保証できない。残る3本も広告後の回遊の影響を受け得るので厳密な対照群にはならない。初期24/72時間観測と広告後の比較は条件を明記して扱う。予算は再承認なしで追加しない。

子ども向け動画で使えないコメント・終了画面等に依存する導線は採用しない。子ども向けの分類は維持する。[YouTube公式：対象視聴者の設定](https://support.google.com/youtube/answer/9527654?hl=en)
